One line (89 characters, limit 200): the funniest honest error message a
washing machine could show — the classic disappearing-sock fault, reported
in the machine's own flat, put-upon voice.

Entry:

> ERROR 404: Sock not found. I checked twice. I am a washing machine, not a miracle worker.

`main.ts` writes the line to `/output/entry.txt` (or
`$MAKEFUN_OUTPUT_DIR/entry.txt`).
